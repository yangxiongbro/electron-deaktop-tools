# 整体要求

该程序整体要求如下

- 基于Electron UI、VUE3、Element UI搭建一个桌面工具应用
- 整体风格简洁，可以切换主题，提供白色、黑色主题选择
- 页面左侧可以折叠\展开，折叠的时候显示图标。展开的时候显示图标和工具名称
- 提供应用设置功能，可以切换主题、文件下载默认目录（后续有下载功能默认下载到该目录）
- 可以打包成Windows、Linux应用，适应x86、x64、ARM架构



# 工具： Json 字符串格式化

该工具具有以下功能

- 要有一个输入框，一个展示框。展示框有一个复制按钮复制格式化之后的json字符串
- 一键清除按钮，可以一键清除输入框和输出框的内容
- 对字符串进行校验是否为json字符串，如果不满足json字符串则提示错误位置
- 将一串字符串格式化，并且可以进行层级折叠
- 为了处理超大字符串，输入的字符串可以从文件中读取，处理完成之后直接输出到输出文件中，不需要展示出来

# 工具：命名规范转换

该工具具有以下功能、做一个按钮进行切换不同功能

- 下划线命名格式字符串转驼峰格式
- 驼峰命名格式字符串转下划线小写格式
- 驼峰命名格式字符串转下划线大写格式
- 其它一些常用的转换功能也可以加上



# 工具：字符串编码\解码

该工具具有以下功能、做一个按钮进行切换不同功能

- 对字符串进行URL编码、解码
- 对字符串进行Base64编码、解码
- 对字符串进行MD5编码、解码
- 其它一些常用的编码解码功能也可以加上



# 工具：API请求工具

该工具具有以下功能

- 可以对GET\POST\PUT\DELETE\文件上传等常用的请求类型进行请求
- 可以设置请求头
- 可以选择不同鉴权方式设置token
- 可以设置请求参数
- 可以设置请求体参数、请求体可以设置form-data、raw等
- 可以选择相应内容直接展示出来或者保存到文件中



# 工具：Markdown编辑器

该工具具有以下功能

- 实现Markdown文件内容展示，对文件内容格式正确展示
- 实现简单编辑功能、可以插入代码块、标题分级等
