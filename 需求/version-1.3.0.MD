# 整体要求

- 更新版本号
- 更新`API请求`工具
- 更新`Markdown编辑器`工具
- 新增`本地聊天`工具



# 工具：API请求

更新以下功能

- 请求结果没有保存，切换到其它请求再回来，之前请求的结果没了
- 接口列表增加接口文件夹，可以创建多级文件夹
- 接口列表每一项只需要展示请求类型、接口名称、请求结果，把复制、删除、创建文件夹操作放到一个弹出菜单中
- 删除文件夹时把删除文件夹下的请求也删除



# 工具：Markdown编辑器

更新以下功能

- 预览时，本来有缩进的文本没有缩进
- 点击保存文件时，要检查文件从上一次保存/打开时到现在是否被其它程序修改过，如果修改过则提示用户是否保存，保存的话会覆盖其它程序的修改，或者另存为另一份新文件，或者取消保存。
- 如果打开文件之后还没有对文件进行修改，此时有其它程序修改该文件，则载入最新的文件内容
- 增加文本搜索功能，搜索当前打开的文件内容，支持大小写开关、整词搜索开关、正则搜索
- 在预览页面滚动之后再直接切到编辑页面，编辑页面没有定位到预览页面的位置



# 工具：本地聊天

该工具具有以下功能

- 通过手动配置好友的ip\端口进行添加好友，添加好友时可以对该好友配置一个备注
- 启动应用时监听聊天端口（默认配置一个少用的端口号，如果可以的话默认配置一个开放的端口\用户可在设置自定义），有新消息时通知用户
- 用户修改信息(端口号\昵称\头像等)时广播给在线的好友。用户收到好友修改信息消息时，自动修改该好友的信息配置
- 在好友列表切换聊天好友时，检查更新该好友的信息（昵称、头像等）是否修改，有修改的话更新该好友的信息
- 好友状态判断如下
  - 在线：好友在使用本程序
  - 离线：好友ip和端口都通，但是没有在使用本程序
  - 不可达：好友ip不可达或者端口不通
- 可以发送文字、图片、文件、表情消息
- 用户列表可以伸缩
- 可以设置头像，生成一些默认头像和昵称，用户第一次使用时配置一个随机头像和昵称
- 可以搜索聊天记录
- 该工具的配置以及好友的设置、聊天记录等要保存到配置文件，以便迁移
- 可以设置聊天过程中产生的文档、图片的保存位置
