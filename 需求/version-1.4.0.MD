# 工具：本地聊天

该工具具有以下问题

- 发送内容为纯数字时，纯数字聊天消息没有被气泡包裹，而且字体和大小也和中文不一样
- 当对方的 HTTPS 证书与上次不一致时，依然可以发送并接收到消息



# 工具：文件同步

该工具具有以下功能

- 可以通过蓝牙或者WIFI进行文件同步
- 可以选择同步到多个设备
- 可以指定一个文件夹为同步文件夹，当文件夹内的文件出现变动时同步文件到连接的设备
- 同步在`android-tools`工程实现该工具，该工程仓库链接：https://github.com/yangxiongbro/android-tools.git，将该工程放到`sub_projects`目录下
